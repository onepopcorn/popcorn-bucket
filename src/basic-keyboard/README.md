# Keyboard Control
A very basic example to show how to control user input via keyboard.

## What you learn
The goal of this example is to show how to detect and interface with the user input via keyboard. For that, we will install a handler to interrupt IRQ9 and see how to handle both, keys being pressed and keys just pressed to prevent bouncing events for actions we just one to happens once per keystroke
